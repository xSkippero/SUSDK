# Skippero Unity SDK

This repository contains a **private SDK** I use across my Unity projects.

It is public mainly so others can:
- Get inspired
- Find random snippets or systems
- Reuse ideas or small pieces of code

There is **no guarantee** that anything in here is:
- Clean
- Optimized
- Stable
- Well-documented
- Even a good idea

Use at your own risk.

---

## What this is

- A collection of **Unity-focused helper code, systems, and utilities**
- Built organically while working on different games
- Code may range from experimental to production-used
- Structure and patterns may change without notice

Some parts may be:
- Half-finished
- Overengineered
- Underengineered
- Highly opinionated
- Written for very specific use cases

---

## What this is NOT

- ❌ A polished, supported SDK
- ❌ A drop-in framework
- ❌ Guaranteed to follow best practices
- ❌ Guaranteed to work outside my projects
- ❌ Actively supported for external users

If something breaks your project, that’s on you 🙂

---

## Usage

You are free to:
- Browse the code
- Copy small parts
- Adapt ideas or patterns
- Learn from mistakes

If you plan to use anything directly:
- Read the code first
- Expect Unity-version-specific behavior
- Expect missing edge cases
- Expect zero backwards compatibility
